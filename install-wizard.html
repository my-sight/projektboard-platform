📦 1. Vorab-Checkliste

Bevor wir starten, stelle sicher, dass du alles bereit hast. Diese Hardware sichert den reibungslosen Betrieb.

  • Intel NUC (oder vergleichbarer Mini-PC)
  • USB-Stick (min. 8GB) für Ubuntu
  • USB-Stick mit Projektordner (vorbereitet am Mac)
  • Internetverbindung (LAN-Kabel wird empfohlen)
  • Bildschirm & Tastatur für den ersten Setup am NUC
💡 Hardware-Tipp: 8GB RAM werden dringend empfohlen. Mit 4GB läuft die Datenbank, aber das System könnte bei vielen Projekten langsam werden.
🖥️ NUC (Hardware-Setup)

💿 2. OS & Docker

Installiere Ubuntu Server 24.04 LTS. Während der Installation wirst du nach einem Benutzernamen und Passwort gefragt. Gut merken!

⚠️ WICHTIG: Wenn du das Passwort am NUC tippst, siehst du keine Sternchen oder Punkte. Tippe einfach blind und drücke Enter.
⚙️ Einstellungen:
  • [x] Install OpenSSH server (damit wir später vom Mac drauf können)
  • [x] Docker (ganz unten in der Liste der "Featured Snaps")

Nutze bei der Festplatte die Option "Use an entire disk" mit LVM & LUKS Verschlüsselung.

🖥️ NUC (Konsole)

🔐 3. TPM-AutoUnlock (Optional)

Damit der NUC nach einem Neustart direkt hochfährt (ohne Passwort), binden wir den Schlüssel an den internen Chip.

sudo apt update && sudo apt install clevis clevis-tpm2 clevis-luks -y sudo clevis luks bind -d /dev/nvme0n1p3 tpm2 '{"pcr_bank":"sha256","pcr_ids":"7"}' sudo update-initramfs -u -k 'all'
Hinweis: Wenn /dev/nvme0n1p3 nicht gefunden wird, nutze lsblk um deine Partition zu finden (oft auch sda3).
🖥️ NUC (Hardware)

📂 4. Dateien übertragen

Stecke den USB-Stick (mit dem Projektordner vom Mac) in den NUC.

1. Stick finden (Suche nach einem Eintrag mit deiner Stick-Größe, z.B. 14.4G):

lsblk

2. Befehle nacheinander ausführen:

sudo mkdir -p /media/usb sudo mount /dev/sdb1 /media/usb cp -r /media/usb/projektboard-platform ~/ sudo umount /media/usb
💡 Achtung: Falls sdb1 im ersten Schritt anders hieß (z.B. sda1), ändere das im zweiten Befehl entsprechend ab!

🐳 5. Docker & Backend Check

Bevor wir die Installation starten, prüfen wir, ob Docker korrekt vorbereitet ist.

1. Docker-Gruppe beitreten (damit Befehle ohne sudo gehen):

sudo usermod -aG docker $USER newgrp docker

2. Docker Status prüfen:

docker ps sudo systemctl status docker
💾 Datenbank-Info: Die Datenbank (PostgreSQL) wird automatisch als Docker-Container gestartet. Es ist kein manueller SQL-Setup nötig!
🖥️ NUC (Finale)

🚀 6. Installation starten

Jetzt bauen wir die Anwendung zusammen. Das dauert je nach Internetgeschwindigkeit 5-10 Minuten.

Installer ausführen:

cd ~/projektboard-platform/deploy chmod +x *.sh ./install.sh
🔄 Netzwerk-Umzug? Falls der NUC später in ein anderes Netzwerk (Firma) kommt, ändere einfach die IP: Führe ./install.sh erneut aus und gib die neue IP ein. Der Installer behält alle Daten und aktualisiert nur die Verbindung!
💡 Hinweis: Wenn das Skript nach der IP fragt, gib die oben eingetragene Adresse ein (oder einfach Enter für localhost, falls du direkt am NUC arbeitest).
💻 MAC (Browser)

✅ 7. Erster Login

Wechsle nun zurück an deinen Mac und öffne den Browser.

🔗 URL im Browser öffnen: http://IP-ADRESSE:3000

Lizenz-Token am Mac generieren:

node scripts/generate_license.js 2026-12-20 "ProjektBoard" 50
🔑 Key-Fehler? Falls die Meldung "Private key not found" kommt, führe einmalig diesen Befehl am Mac aus: node scripts/generate_keys.js

Kopiere den Token (den langen Text) aus dem Terminal und füge ihn auf der /license Seite der App ein.
