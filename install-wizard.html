📦 1. Vorab-Checkliste

Bevor wir starten, stelle sicher, dass du alles bereit hast. Diese Hardware sichert den reibungslosen Betrieb.

  • Intel NUC (oder vergleichbarer Mini-PC)
  • USB-Stick (min. 8GB) für Ubuntu
  • USB-Stick mit Projektordner (FAT32/ExFAT)
  • Internetverbindung am NUC (WLAN/LAN)
💡 Hardware-Tipp: 8GB RAM werden dringend empfohlen, damit Datenbank und App gleichzeitig performant laufen.

💿 2. OS & Docker

Installiere Ubuntu Server 24.04 LTS auf dem NUC. Achte auf folgende kritische Einstellungen während des Setups:

⚠️ Wichtig während der Installation:
  • [x] Install OpenSSH server ankreuzen
  • [x] Docker (Featured Server Snaps) unbedingt auswählen!

Wähle bei der Festplatte "Use an entire disk" und aktiviere LVM & Verschlüsselung (LUKS) für maximalen Datenschutz.

🔐 3. TPM-AutoUnlock (Optional)

Damit der NUC nach einem Stromausfall automatisch startet, aber verschlüsselt bleibt, binden wir den Key an den TPM-Chip.

sudo apt update && sudo apt install clevis clevis-tpm2 clevis-luks -y sudo clevis luks bind -d /dev/nvme0n1p3 tpm2 '{"pcr_bank":"sha256","pcr_ids":"7"}' sudo update-initramfs -u -k 'all'

Hinweis: Prüfe mit lsblk, ob deine Partition wirklich nvme0n1p3 heißt.

🚀 4. Deployment

Übertrage den Ordner projektboard-platform auf den NUC und starte den Installer.

cd projektboard-platform/deploy chmod +x *.sh ./install.sh

Spätere Updates (z.B. nach Code-Änderungen):

cd projektboard-platform/deploy ./update.sh

Während der Installation wirst du nach der IP gefragt. Nutze: localhost

✅ 5. Abschluss & Lizenz

Sobald die Installation durchgelaufen ist, kannst du das System über den Browser deines Macs erreichen.

🔗 URL: http://IP-ADRESSE:3000

Erzeuge jetzt die Lizenz auf deinem Mac:

node scripts/generate_license.js 2026-12-20 "ProjektBoard" 50
